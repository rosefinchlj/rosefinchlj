### Hi, I'm rosefinchlj 👋

我在用 Rust 做一些 Windows 桌面小工具（也是 Rust 实践学习项目）：

| 项目 | 说明 | 下载 |
|---|---|---|
| **[lstr](https://github.com/rosefinchlj/lstr)** | Windows 启动器：自研文件索引 + egui 界面，双击 Ctrl 唤出，文件 / 应用 / 书签 / 笔记 / 命令一个框搜；支持资源管理器贴角浮层与文件对话框停靠条。Rust，单文件 exe。 | [Releases](https://github.com/rosefinchlj/lstr/releases) |
| **[ClipNest 剪贴匣](https://github.com/rosefinchlj/clipnest)** | Windows 剪贴板历史管理器：中文搜索、图片/文件历史、收藏与回收站，本地 SQLite 零联网。Rust + egui，单文件 exe，MIT。 | [Releases](https://github.com/rosefinchlj/clipnest/releases) · [介绍页](https://rosefinchlj.github.io/clipnest/) |
| **[exptab](https://github.com/rosefinchlj/exptab-rs)** | Windows 11 资源管理器窗口自动并入标签（新窗口变成主窗口标签页）。Rust 单文件 413 KB，无 .NET 依赖，MIT；C# 版 ExplorerTabUtility 的 Rust 重写。 | [Releases](https://github.com/rosefinchlj/exptab-rs/releases) · [介绍页](https://rosefinchlj.github.io/exptab-rs/) |

- 🔧 技术栈：Rust · Win32 API · COM · SQLite/FTS5 · egui/eframe
- 🌐 项目枢纽：https://rosefinchlj.github.io/
- 📫 欢迎 issue / PR / 提建议

> Three small open-source Windows utilities written in Rust: a launcher (lstr), a clipboard history manager (ClipNest) and a File Explorer tab-merging tool (exptab).
